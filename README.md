# AI学习笔记

在这里记录我从零开始学习AI的过程。目前我主要以《AI工程：大模型应用开发实战》作为此次学习之旅的基本框架，每篇笔记会围绕一个或几个问题展开，也会记录由此引发的进一步探索。

## 已有笔记

| 文章                                              | 主要讨论的问题                                                         |
| ----------------------------------------------- | --------------------------------------------------------------- |
| [分词与词元](./AI学习笔记-分词与词元.md)                      | 词元是什么？分词是一个什么过程，依据什么原则？分词结果会与人类理解的语言结构相符吗？中文与模型交互是否会比英文更省词元？    |

每一篇笔记应该都会有AI高度参与，先说明一下我和AI的角色分工或许会比较合适：我负责选题、文章结构和具体写作，AI主要协助检索资料、总结和解释文献，并在定稿前检查可能存在的事实或逻辑错误，修改意见会由我决定是否采纳以及如何修改。将零散的材料和讨论组织成文章，对我而言也是重要的思维训练，因此我希望自己完成主体写作。

这个组织和写作过程其实是一件很有趣的事！在这个过程中，我们需要能够从材料中识别并抽取自己需要的部分，使其脱离原本的结构，加入并服务于新的整体，各种信息会像浪潮一样，一次又一次地将我们淹没，而我们需要在一片混乱和不确定中找到那条通往海面的线索，每一次破出水面，我们的思维和意志都会变得更加强韧。

目前（以及在可预期的未来），我对相关论文的了解主要依靠AI的总结和解释，没有逐篇阅读与核对原文，我会在文末列出文献信息，便于自己以后感兴趣时能够继续查阅，也方便读者检查相关说法。虽然我和AI的多轮讨论会让一些错误浮现出来并得到修正，但我毕竟没有自己去读过这些文献，也会受到个人认知和视角的局限，所以很可能还是会存在错误或解释不充分的地方。我会努力做到自己能做的事，修改自己能够修改的地方，尽量区分资料中的结论、我个人的理解和推测，以及观察到的现象，以求降低可能带来的误导。

如果发现问题，欢迎指出具体段落，并提供可查证的依据。对我来说，发现并修正理解的错误，也是学习和写这些笔记的一部分，非常感谢！
